# survival-quiz

Quiz-Videos „Was würdest du tun?“ im Hochformat (1080×1920, 30 fps), gebaut mit Remotion + 3D.

- Regeln, Look und Ablauf: siehe [CLAUDE.md](CLAUDE.md)
- Szenarien (ein Video = eine Datei): `scenarios/`
- Standbilder zur Freigabe: `review/`

Vorschau starten: `npm install` und dann `npm run studio`
